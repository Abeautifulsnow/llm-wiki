# CLI Installation

## Binaries

The CLI is distributed as a single static binary for Windows, macOS, and Linux.

Checksums are published next to every release.

## Requirements

The CLI requires Python 3.10 or newer when installed through the package manager.

Run `nimbus doctor` to verify the local installation.

The static binary has no runtime dependencies.
