# Platform Overview

## What Nimbus provides

Nimbus abstracts the infrastructure so teams can focus on event-driven features.

Nimbus is a managed platform for publishing, streaming, and storing event data.

Every Nimbus project runs in exactly one region, and data never leaves that region unless replication is enabled.

## Core building blocks

The four core building blocks of Nimbus are topics, queues, streams, and buckets.

Nimbus exposes all building blocks through a REST API, a command-line interface, and managed SDKs.

Each building block has its own quota, pricing, and consistency model documented in this wiki.
