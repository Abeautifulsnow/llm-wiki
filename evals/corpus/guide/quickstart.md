# Quickstart

## Create a project

The init command scaffolds a project directory with a manifest and sample code.

A new Nimbus project can be created with `nimbus init my-project`.

## Deploy and verify

The quickstart deployment finishes in under five minutes for projects with fewer than fifty resources.

Every quickstart example is written in Python 3.

After deployment the CLI prints the regional endpoint of the new project.
