# Buckets

## Quotas

Buckets are billed by stored volume and egress, not by object count.

Each project can create up to 100 buckets.

Objects in a bucket can be up to 5 TiB each.

## Naming

Bucket names are immutable after creation.

Choose names that will still make sense after a team rename.
