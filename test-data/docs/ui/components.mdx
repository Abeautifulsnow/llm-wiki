# UI Components

Documentation-site components used across the manual.

## Callout

Use a callout to highlight information.

<Callout type="warning" title="Check versions">

Callout text supports **markdown** formatting, but not arbitrary JSX.

</Callout>

## Tabs

Tabs group alternative instructions per platform.

<Tabs defaultValue="win">

- `win` — Windows instructions
- `mac` — macOS instructions

</Tabs>

<Badge label="Stable" tone="green" />

The `Badge` component marks feature stability.
